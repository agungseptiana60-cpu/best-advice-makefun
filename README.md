A tiny program for the make.fun bounty
[The Best Advice I Ever Got](https://make.fun/bounty/u-pangg7-the-best-advice-i-ever-got-358cefb0).

Running `main.ts` writes a single sentence, at most 200 characters, about
the best advice ever received to `/output/entry.txt` (or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).

## Run it

```sh
node main.ts
```
